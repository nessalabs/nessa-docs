# Glossary

Each heading is one acronym. Pages under this folder link every use of it here.

## ADR

Architecture decision record. One numbered decision in `docs/decisions.md`, with
what was chosen and why.

## ID

Identifier. The fixed name a page, order or payment is known by.

## SDK

Software development kit. The small client library a caller uses to attach to
an order and write to it.

## UI

User interface. The screens a person uses to place and follow an order.
